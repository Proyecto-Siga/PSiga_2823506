<h1 align="center">SIGA</h1>
<h3 align="center">Sistema de Ingreso General Académico</h3>

---

## 🎯 Objetivo General

Desarrollar e implementar un sistema de información para el registro de los estudiantes a las aulas de clase en los colegios públicos de la ciudad de Bogotá D.C.

---

## ✅ Objetivos Específicos

- Facilitar el registro de asistencia de los estudiantes para los docentes y administrativos.
- Capturar y gestionar la información de estudiantes y acudientes.
- Permitir el acceso a la información de asistencia en tiempo real.

---

## ❓ Pregunta Problema

> ¿Es importante el control de asistencia en las instituciones educativas y el oportuno registro, control y reportes de las mismas para los acudientes y/o padres de familia?

---

## 🔍 Planteamiento del Problema

El sistema actual de control de asistencias en las instituciones educativas es obsoleto y presenta múltiples falencias.  
- ❌ **Toma de asistencia manual** que interrumpe clases.  
- ❌ **Falta de comunicación en tiempo real** con acudientes.  
- ❌ **Registros físicos vulnerables** a daños o pérdidas.  
- ❌ **Posibilidad de suplantación** de identidad por falta de verificación digital.

---

## 📌 Alcance del Proyecto

El sistema está orientado a las instituciones educativas públicas de Bogotá D.C., permitiendo:
- Registro digital de asistencia mediante biometría o código.
- Administración de usuarios según roles (docentes, directivos, administrativos).
- Acceso web responsivo desde cualquier dispositivo.
- Reportes en tiempo real sobre la asistencia diaria.

---

## 🛠️ Tecnologías Utilizadas

- **Frontend:** React.js + CSS personalizado  
- **Backend:** Laravel (PHP) + API REST  
- **Base de Datos:** MySQL  
- **Control de versiones:** Git + GitHub
